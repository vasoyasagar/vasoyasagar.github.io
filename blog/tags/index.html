      All concepts

      A

      Autoregressive decoding
      How LLMs generate: one token at a time, each conditioned on the tokens before it. Structured JSON is generated the same way.

      B

      Brier score
      The mean squared gap between predicted probabilities and 0/1 outcomes. Lower is better, and confident mistakes cost the most.

      C

      Calibration
      Whether probabilities match outcomes: among many answers given probability 0.8, about 80% should be right. Measured over many predictions.
      Choice
      A question type that picks one option from a defined set of up to 255, returning the probability of every option and a confidence.
      Confidence
      A number from 0 to 1 computed from an answer's probability distribution. High when probability is concentrated; it doesn't say the answer is right.
      Context window
      The most input a model accepts in one request. Jev allows 64K tokens, with 32K for the state plus the longest question.

      E

      Entropy
      A measure of how spread out a probability distribution is: zero when all probability is on one answer, highest when it is uniform.

      G

      Guardrail
      A check that screens an input, an output or a proposed action such as a tool call, before it is allowed to proceed.

      J

      Jaggedness
      TypeSafe's name for Jev's known weak spots, such as counting, arithmetic, date comparison and reading instructions too literally.
      Jev
      TypeSafe's System One model. It answers typed questions about an input with probabilities, and can't generate text.

      L

      Latency
      The time a request takes from sending to answer. Usually reported as the median and a slow-tail percentile such as p90.
      LLM
      Large language model: a model trained to predict the next token, used to generate text, code and structured output.

      N

      Noul
      A yes/no question type. The answer is the probability that the answer is yes, from 0 to 1. Nouls carry no separate confidence.

      R

      Reranking
      Re-ordering retrieved candidates by a relevance score, so the best ones reach the answering model first.
      RLCD
      Reinforcement learning for calibrated decisions: TypeSafe's training approach for models that return decisions with calibrated probabilities.
      Routing
      Sending each request to the right handler, such as a model, an agent, plain code or a person, based on a quick classification.

      S

      Score
      A question type that rates the input on ordered levels you describe. The score is the probability-weighted mean of the level numbers.
      Speculative fan-out
      Asking every question you might need in one request, then letting code decide which answers matter, instead of chaining calls.
      State
      The input a System One model evaluates: a string, a JSON object or an array of text. Every question in a request is asked about the same state.
      Structured outputs
      Getting machine-readable answers (JSON, enums, numbers) from a model instead of free text, so code can use them directly.
      System One model
      A model that makes fast, structured decisions: it evaluates an input against typed questions and returns probabilities instead of text.

      T

      Token
      The unit of text a model reads and writes, usually a word or part of one. Prices and context limits are counted in tokens.
