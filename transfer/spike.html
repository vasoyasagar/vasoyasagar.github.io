Envoyer · Phase 0 network test

Open this page on 2–3 devices on the same Wi-Fi. Run 1–2 on each device, then use 3–4 between devices.

This device:

1 · Public IP probe

All devices on the same Wi-Fi should show the same IPv4. Auto-discovery depends on this.

Connects to each public broker over wss and times a message round trip.

Join the same room on every device. Keep All brokers (the Phase 1 behavior). Pick a peer and Connect. The connection uses iceServers: [], so it can only succeed on the local network.

    7 · Speed lab (between two devices)
    
      
    Join the room and Connect in section 3 on both devices. Then, on the sending device, tap Speed lab next to the other one. It runs 4 tests of 15 s each (about 1½ minutes): 1 connection as the app works today, 1 connection with bigger messages, then 2 and 4 parallel connections. Keep both screens on.
