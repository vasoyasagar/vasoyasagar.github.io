    Envoyer

    Send anything between devices on the same Wi-Fi

    Send files, text and links between any two devices on the same network, straight from the browser: no install, no account, and the bytes never touch a server. Peers connect over WebRTC, with end-to-end encrypted signaling relayed through several public MQTT brokers at once.

    • Automatic nearby discovery
    • Any file size, streamed to disk
    • Resumes after short drops
    • Emoji security code
    • Android share target
    • React 19
    • WebRTC
    • MQTT
    • @noble/curves
    • fflate
